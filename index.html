Project Summary

Move-In is a full-stack moving marketplace application developed as a capstone project at George Brown College. The platform connects customers who need moving services with movers offering their expertise, streamlining the process of finding, comparing, and booking professional moving help. Built with React on the frontend and Node.js/Express on the backend, it features Supabase for data persistence and authentication.

Project Vision

To create a seamless, trustworthy platform that simplifies the moving experience. Move-In envisions a marketplace where customers can easily discover vetted movers, get instant estimates, view reviews, and book services — all in one place. For movers, the platform provides a channel to reach customers, manage bookings, and grow their business.

Business & Project Requirements

👤 User Management

Secure registration and login with role-based access for customers and movers

🔍 Service Discovery

Browse, search, and filter moving services by location, price, and ratings

📅 Booking System

Real-time booking flow with date selection, confirmation, and status tracking

⭐ Reviews & Ratings

Customer feedback system to build trust and quality assurance

🛠 Mover Dashboard

Service management, booking tracking, and profile customization for movers

📱 Responsive Design

Fully responsive interface that works across desktop, tablet, and mobile

Architecture & Design

Frontend (apps/web)

React SPA built with Create React App, featuring component-based architecture, React Router for navigation, and a clean responsive UI.

Backend (apps/api)

Node.js + Express REST API layer handling business logic, authentication, and data validation with Supabase as the data store.

Database & Auth

Supabase provides PostgreSQL-backed data persistence, user authentication, and real-time capabilities out of the box.

Project Plan & Timeline

Phase 1 Planning & Requirements

Project scoping, requirements gathering, user stories, and wireframe design

Phase 2 Design & Prototyping

UI/UX design, component mockups, database schema, and API contract definitions

Phase 3 Core Development

Frontend scaffolding, API endpoints, Supabase integration, and auth flow implementation

Phase 4 Feature Implementation

Booking system, search/filter, mover profiles, reviews, and dashboard features

Phase 5 Testing & Deployment

Integration testing, bug fixes, performance optimization, and final deployment
